# AGENTS.md — FairPick

Guidance for Thatch (the developer of record) and any future agent working on this repository. This project follows **UAES-001 v1.0, Level 1** — see `PROJECT-COMPLIANCE.md` in the repository root. This file lives in `docs/` so the repository root stays clean and focused on the app itself. The UAES standards repository (rayjoshuaa/application-engineering-standards) is a read-only reference: never edit it.

## What this is

A random student picker for the classroom screen with a fairness guarantee: nobody is picked twice until everyone has had a turn, then a new round starts automatically. Since v3.0.0 it is a React + Vite + TypeScript app built **only** from shadcn/ui components, in the design language of ClassTimer+ v2.1.5 (the first Teacher Tools app and the Project Owner's settled design reference). v1.0.0–v2.0.0 were a single self-contained `index.html`; that build lives in the sibling `fairpick/` folder and must not be edited from here.

## Invariants — do not break

- localStorage keys and shapes: `fairpick_draft` (the raw class-list text, a plain string — NOT JSON), `fairpick_state` (`{picked: string[], round: number}`), `fairpick_lists` (object mapping list name → raw list text). Existing teachers' saved lists must keep working across versions — never rename these keys or change the shapes.
- Fairness rule: the pick pool is always the names not yet picked this round. When the pool empties, picked resets and the round counter increments before the pick is made from the full list. The **New round** button is different: it clears picked and resets the round counter to **1**. Names are de-duplicated case-insensitively when parsing the list (trim each line, drop blanks, first spelling wins). Picked names that are no longer on the list are filtered out everywhere (display, counts, progress).
- Safety: names are only ever rendered as React text — never `dangerouslySetInnerHTML` or any HTML injection with user text. All localStorage reads are guarded with try/catch.
- Sound: spin ticks (340–400 Hz, 0.05 s) plus a two-note landing chime (659.25 Hz then 880 Hz), gain envelope 0.0001 → 0.18 → 0.0001, all gated by the Sound switch. Audio must be created/resumed inside a user gesture (`warmAudio()` is called from Pick).
- Screen-reader announcements go to the sr-only `aria-live` region on state changes only (pick landed, round rollover, new round, list saved/loaded/deleted, sample loaded) — never during the spin.
- Feedback instead of silence: picking with no names, saving without a list name, saving with no names, and loading/deleting with no list chosen must explain themselves in the reserved feedback lines and move focus to the field that needs attention. Feedback lines are permanently reserved slots (fixed height) so state changes never move the layout.
- Design rules (from ClassTimer+, Project Owner direction 2026-11-25 — "just reference the first app"): shadcn/ui components only, neutral base, Geist; one fixed screen (`h-svh`, body overflow hidden, no page scrolling) with the card filling the viewport height; "Teacher Tools" Badge + app title + one-line description header (descriptions hide under 720px viewport height); section titles bold like titles (`text-base font-semibold`); buttons with fixed widths so labels/state never shift the layout; the picked name sits in a fixed-height box; long content (name chips) scrolls inside its own area only. Favicon is the black & white Teacher Tools `shuffle` icon at `public/icon.svg` — **no brand mark on the page**. Footer: keyboard hints in the card footer; "© 2026 Ray Joshua. All rights reserved." below the card, his name linked to https://rayjoshuaa-portfolio.pages.dev. Tab title: idle "Teacher Tools: FairPick"; after a pick "FairPick | <name>"; New round resets it. Picked names on the class board carry a tick and strikethrough — status is never colour alone. The spin animation is skipped under `prefers-reduced-motion` (and when the Spinning animation switch is off), and the landing `land` keyframes in `src/index.css` are disabled there too.
- Keyboard: Space pick, N new round, F fullscreen — all inert while typing in an input/textarea/select (the Radix Select trigger is a button with `role="combobox"` — it is guarded too), and Space never fires when a button has focus (it would double-trigger).
- shadcn components are used **verbatim, unmodified**. The shadcn CLI writes new components into a literal `@/` folder in this project; move them into `src/components/ui/` unchanged after adding.

## Workflow

- Commit prefixes per UAES-001 §14: `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`.
- Before calling anything done (UAES-001 §19): `npm run build` (type-check + production build), test success + invalid + failure flows, check responsive behaviour and accessibility, update `CHANGELOG.md` and docs.
- Deployment: Cloudflare Pages is Git-connected to this repo — pushing to `main` deploys automatically. The v3.0.0 rebuild needs the Pages project's build settings changed to build command `npm run build`, output `dist` (v2.0.0 was served from the repo root with no build). Commit first, verify the live site after the deploy, and record the release in `CHANGELOG.md`.
